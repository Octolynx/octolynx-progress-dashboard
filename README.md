# Octolynx project progress

This public site displays only approved aggregate project-board counts. It does not expose issue titles, descriptions, people, or links. Epic and user-story progress remains unavailable until the private tracker has a reliable hierarchy.

The private tracker maintains `data.json` using its scheduled snapshot workflow. The timestamp is the time the source was read; check it to assess freshness. Done is a board status, not proof of production readiness. Failed updates leave the last snapshot in place.
